# News Lingua API

Express API for authentication, MongoDB storage, AI summarization, and text-to-speech.

## Local development

1. Copy `.env.example` to `.env.local` and set the required values.
2. Run `npm install`.
3. Run `npm run dev`.

The API listens on `http://localhost:5000` by default. See [DEPLOYMENT.md](DEPLOYMENT.md) for the full testing and deployment checklist.
