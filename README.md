# News Lingua

AI-powered multilingual news summarizer.

- `frontend/` — Vite/TanStack React application. Deploy this directory to Vercel.
- `backend/` — Express API, MongoDB persistence, authentication, email verification, and AI services. Deploy this directory as a separate Node.js service.

See [frontend/README.md](frontend/README.md) for frontend development and [backend/DEPLOYMENT.md](backend/DEPLOYMENT.md) for backend setup.
